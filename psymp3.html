PsyMP3 Music Player

PsyMP3 is a cross-platform music (audio) player written in C++ using SDL. PsyMP3 has support for an array of audio codecs, including MP3, Vorbis, Opus, and FLAC, as well as uncompressed or "raw" audio in PCM, a-law, and mu-law formats.

PsyMP3 is licensed under the ISC License.

PsyMP3 2.x has been known to run on Windows, Linux, FreeBSD, NetBSD, and OpenBSD.

PsyMP3 2.x has been known to run on x86-32, x86-64, ARM32, and ARM64.

Using PsyMP3

PsyMP3 has a simplified user interface. you may navigate the program using the mouse and menus, or via keyboard shortcuts. To open files, you can use the Open Track option from the File menu, press the "I" key, or drag-and-drop files from a file manager.

PsyMP3 includes a full seven-band graphic equalizer with several presets.

There is an album art mode added in 2.2-RELEASE - pressing the "A" key will toggle between showing the visualizer and the album art of the playing track.

History

PsyMP3 was started as a personal project in FreeBASIC using FMOD in 2008. In 2011, the old FreeBASIC codebase was set aside and the entire project was rearchitected from the ground-up in modern C++, using advanced features of C++17 to achieve high-performance and memory safety.

Currently supported media formats

PsyMP3 supports multiple media formats:

  • MP3
  • Vorbis
  • Opus
  • AAC, HE-AAC, xHE-AACM
  • FLAC
  • ALAC
  • Dolby Digital (AC-3)
  • Dolby Digial Plus (E-AC-3)
  • Dolby TrueHD
  • PCM
  • a-law
  • mu-law
  • G.722

PsyMP3 supports multiple container formats:

  • Ogg
  • RIFF (.WAV and .AVI)
  • AIFF (Apple)
  • FLAC native container
  • ISO base media format (.mp4)
  • Maktroska (.mkv) and WebM

PsyMP3 also supports reading metadata tags for all of these, using built-in parsers for ID3v1 and ID3v2.x as well as VorbisComment. Other formats are supported through TagLib.
